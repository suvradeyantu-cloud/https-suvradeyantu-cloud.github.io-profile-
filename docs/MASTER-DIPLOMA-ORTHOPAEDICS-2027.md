# 📋 SYLLABUS & EXAM-PATTERN ANALYSIS
### BMU/BSMMU Diploma & MPhil (July 2026) · BSMMU Residency (March 2026)

---

## 1. The reality of the "syllabus"
BMU/BSMMU **does not publish a fixed topic-by-topic syllabus** for the Diploma or
Residency entrance. The admission notice (e.g., *BMU Admission Notice for M.Phil,
M.MEd & Diploma Courses — July 2026*, bmu.ac.bd/notices) specifies eligibility,
seats, exam format and dates — **not** a content list. Preparation therefore mirrors
the MBBS curriculum weighted toward Basic Sciences + Faculty Surgery + Orthopaedics,
plus the documented question-bank trends.

## 2. Exam-format analysis (synthesised from notices + banks)
| Parameter | BMU/BSMMU Diploma (D.Ortho) | BSMMU Residency (Ortho) MCQ |
|---|---|---|
| Type | MCQ / SBA | MCQ / SBA |
| Total marks | ~100 | ~100–200 |
| Duration | ~1 hour | ~2–3 hours |
| Negative marking | Usually none / minimal (verify per notice) | Verify per notice |
| Domain split | Basic Sciences + Surgery + Orthopaedics | Same, deeper ortho |
| Style | Single-best-answer, "EXCEPT", "Most common", "Best next step" | Same + image-based |

> **Action:** Always re-read the specific year's notice for marks, duration and
> negative-marking before you sit. The pattern above is the stable historical norm.

## 3. Implied subject weightage (from repeated-bank analysis)
| Block | Est. weight | Notes |
|---|---|---|
| Basic Sciences (Anat/Physio/Biochem/Path/Pharma/Micro) | 30–35% | Anatomy & Pathology dominate |
| Faculty Surgery (trauma, wounds, vascular, hand, amputation) | 25–30% | Trauma/ortho-adjacent surgery heavy |
| Orthopaedics (fractures, pediatrics, spine, joints, tumors, infection) | 35–40% | The "decider" block |
| Image-based / X-ray / photo | 5–10% | Rising trend |

## 4. BMU Diploma vs BSMMU Residency — key differences
- **Diploma:** Broader basic-science & general-surgery coverage; ortho depth moderate.
- **Residency:** Heavier ortho sub-specialty, more clinical-scenario SBAs, more
  image-based X-ray interpretation, higher cut-off.
- **Overlap (use it):** Fracture classifications (Garden, Gustilo, Salter-Harris,
  Weber/Lauge-Hansen), nerve injuries, compartment syndrome, osteomyelitis, AVN,
  pediatric hip, spine TB, OA/RA — appear in **both**.

## 5. Documented pattern features (Bangladesh banks)
- **Classification questions** are the single most repeated format (Garden I–IV,
  Gustilo I–III, Salter-Harris I–V, Weber A/B/C, Schatzker, Evans, Gartland, Cobb).
- **"Most common…"** stems dominate (organism, site, tumor, fracture, nerve injury).
- **EXCEPT / NOT true** stems test precision — high discriminator.
- **Image-based** (X-ray of Colle's, scaphoid, NOF, supracondylar, scoliosis) rising.
- **Numericals** occasionally tested (Bohler's angle >20°, Cobb >10°, Schober <4 cm).

## 6. What raises yield in the Bangladesh context (epidemiology)
- **Road-traffic trauma** → open fractures, femoral/pelvic, polytrauma.
- **Spinal TB (Pott's)** → cold abscess, paraplegia — highly tested in BD.
- **Vitamin-D deficiency / rickets / osteomalacia** → endemic.
- **Osteomyelitis (paediatric haematogenous)** → femur/metaphysis.
- **Diabetic foot / Charcot joint** → rising non-communicable burden.

## 7. Strategic implication
Weight your 3-month plan as **Ortho 40% · Basic Sciences 33% · Surgery 27%**, with a
daily 20-question SBA drill and a weekly image/X-ray session. This matches the
observed weightage and the BMU/BSMMU pattern.

## 3. Stem-style trend (what examiners love)
- **"All of the following are true EXCEPT"** — tests the one outlier.
- **"The most common / earliest / latest / best"** — superlative stems.
- **"The following investigation is the investigation of choice"** — MRI for AVN/disc;
  X-ray first for trauma; USG for DDH <6 mo.
- **"First-line management"** — e.g., Ponseti for CTEV, Pavlik for DDH, debridement +
  ABx for open fracture.

## 4. Classic distractor traps (memorise to avoid)
- Pulselessness = **LATE** sign of compartment syndrome (pain + pain on passive stretch
  are early).
- Proximal scaphoid # AVN affects **proximal pole**, not waist.
- Posteromedial (posterior) hip dislocation injures **sciatic**, not femoral nerve.
- Fat embolism classically after **long-bone** (femur/tibia) fractures, not skull.
- Ewing's = **diaphysis**, osteosarcoma = **metaphysis**.
- RA cervical **subluxation** is a pre-op airway risk; not OA.
- In DDH, **Ortolani = reducible click**, Barlow = dislocatable.

## 5. Year-on-year direction (2024 → 2027)
- ↑ Image-based / X-ray interpretation.
- ↑ Clinical-scenario SBAs over pure fact recall.
- ↑ Bangladesh-epidemiology items (spinal TB, trauma, vitamin-D).
- → Stable core: classifications, nerve injuries, pediatric hip, tumors, arthritis.

## 6. How to exploit the trend
1. Build a **classification flash-card deck** (one card per classification).
2. Drill the **"most common / EXCEPT"** stem library daily.
3. Do **one X-ray-per-day** (Colle's, NOF, supracondylar, scaphoid, scoliosis, TB spine).
4. Convert every topic in `04-TOP-100-INDEX.md` into a 1-line SBA in your own words.

# 📘 PART 1 — BASIC SCIENCES (Topics #1–#25)
*High-Yield Notes · Rapid Revision · Repeating SBA/MCQ · Explanation · Trend · Clinical · Examiner Tip · Reference*

## 1. Brachial Plexus ⭐⭐⭐⭐⭐ (Anatomy)
- **Notes:** Roots C5–T1 → trunks (upper C5–C6, middle C7, lower C8–T1) → divisions (ant/post) → cords (lateral/medial/posterior, named by relation to axillary artery) → branches.
  - Erb's palsy (C5–C6): "waiter's tip" — adducted, internally rotated, extended elbow (obstetric traction / shoulder dystocia).
  - Klumpke's (C8–T1): claw hand + Horner's (ptosis, miosis, anhidrosis) if T1/stellate involved.
- **Rapid Rev:** "Reach To Drink Cold Beer" = Roots→Trunks→Divisions→Cords→Branches. Posterior cord → radial, axillary, thoracodorsal, subscapular.
- **SBA:** A baby with "waiter's tip" posture after difficult delivery has lesion of: **a) C5–C6 (Erb's)**.
- **MCQ:** Klumpke palsy is associated with: **Horner's syndrome**.
- **Explanation:** Upper trunk (C5–C6) supplies deltoid/biceps → loss gives the characteristic posture.
- **Trend:** Repeated in diploma & residency; "waiter's tip" & Horner's are evergreen.
- **Clinical:** Obstetric brachial plexus palsy; also RTAs (traction).
- **Examiner Tip:** "Waiter's tip" = Erb's (upper), NOT Klumpke. Horner's = lower (Klumpke).
- **Ref:** Gray's Anatomy, ch. Upper limb innervation.

## 2. Sciatic & Common Peroneal (Fibular) Nerve ⭐⭐⭐⭐⭐ (Anatomy)
- **Notes:** Sciatic (L4–S3) = tibial + common peroneal; exits via greater sciatic foramen below piriformis, runs in posterior thigh. Common peroneal winds round neck of fibula → foot drop ( dorsiflexion/eversion loss).
- **Rapid Rev:** Hip posterior dislocation & # neck femur → sciatic (often common peroneal branch). Total knee replacement → common peroneal palsy.
- **SBA:** Foot drop after a fibular-neck injury is due to lesion of: **common peroneal nerve**.
- **MCQ:** Sciatic nerve is formed by: **L4, L5, S1, S2, S3**.
- **Explanation:** Common peroneal is superficial at fibular neck → vulnerable to traction/casts.
- **Trend:** Very high — nerve-injury stem favourite.
- **Clinical:** Knee replacements, sciatic nerve block, comet-tail palsy.
- **Examiner Tip:** Foot drop = common peroneal; not tibial (tibial → plantarflexion loss, "foot slap"/calcaneal gait).
- **Ref:** Gray's, lower limb.

## 3. Femoral Triangle & Canal ⭐⭐⭐⭐ (Anatomy)
- **Notes:** Inguinal lig (superior), sartorius (lateral), adductor longus (medial). Contents (lat→med): femoral nerve, artery, vein, empty canal, lymph (NAVEL mnemonic). Femoral canal = medial, site of femoral hernia. Saphenous opening (fossa ovalis) in fascia lata — saphenous vein pierces it.
- **Rapid Rev:** NAVEL = Nerve, Artery, Vein, Empty, Lymph. Femoral hernia = below inguinal lig, medial to pubic tubercle.
- **SBA:** Most medial structure in femoral canal: **lymph node / empty space**; femoral hernia arises here.
- **MCQ:** Femoral hernia is common in: **females** (wider pelvis).
- **Explanation:** Femoral canal is the only weak point → hernia; risk of strangulation.
- **Trend:** High; anatomy-of-groin question.
- **Clinical:** Femoral hernia vs inguinal hernia differentiation.
- **Examiner Tip:** Femoral hernia = inferolateral to pubic tubercle; inguinal = superomedial.
- **Ref:** Gray's, lower limb.

## 4. Popliteal Fossa ⭐⭐⭐⭐ (Anatomy)
- **Notes:** Diamond space behind knee. Contents (superficial→deep): tibial nerve, popliteal vein, popliteal artery (TVA). Popliteal artery most vulnerable to aneurysm / entrapment.
- **Rapid Rev:** "TVA" order from superficial to deep: Tibial nerve, Vein, Artery.
- **SBA:** Deepest structure in popliteal fossa: **popliteal artery**.
- **MCQ:** Popliteal aneurysm most commonly affects: **popliteal artery**.
- **Explanation:** Artery lies deepest, against tibia → protected but dangerous if injured.
- **Trend:** Moderate-high; artery/nerve relation question.
- **Clinical:** Baker's cyst, popliteal aneurysm, soft-tissue tumours.
- **Examiner Tip:** Artery is DEEPEST (not vein).
- **Ref:** Gray's.

## 5. Carpal Tunnel ⭐⭐⭐⭐⭐ (Anatomy)
- **Notes:** Osteofibrous tunnel at wrist; median nerve + 9 flexor tendons (FPL, 4 FDS, 4 FDP). Thenar muscles (thenar eminence) = median (recurrent branch) except adductor pollicis (ulnar). Tests: Phalen (full wrist flexion 60 s), Tinel (tap median nerve).
- **Rapid Rev:** Median nerve = LOAF (Lumbricals 1–2, Opponens pollicis, Abductor pollicis brevis, Flexor pollicis brevis). "Ape hand" = median (thenar wasting).
- **SBA:** Classic finding in carpal tunnel: **thenar wasting + paraesthesia in thumb/index/middle**.
- **MCQ:** Median nerve supplies all EXCEPT: **adductor pollicis (ulnar)**.
- **Explanation:** Recurrent branch of median supplies thenar; compression → aple-hand/weak pinch.
- **Trend:** Very high; "EXCEPT" and muscle-supply stems.
- **Clinical:** Pregnancy, RA, hypothyroidism, repetitive strain.
- **Examiner Tip:** Adductor pollicis = ULNAR (not median) — classic trap.
- **Ref:** Gray's / Snell, hand.

## 6. Hip Joint Blood Supply ⭐⭐⭐⭐⭐ (Anatomy)
- **Notes:** Medial circumflex femoral artery (MCFA) → retinacular branches (posterior superior/inferior) = main intra-capsular blood to femoral head. foveal artery (ligamentum teres) minor in adults. Intertrochanteric (extracapsular) has rich anastomosis → heals; neck (intracapsular) precarious → AVN.
- **Rapid Rev:** MCFA = "Medial = Most important." Intracapsular # → retinacular vessels torn → AVN/nonunion.
- **SBA:** Main blood supply to femoral head: **medial circumflex femoral artery (retinacular vessels)**.
- **MCQ:** Fracture with highest AVN risk: **intracapsular femoral neck fracture**.
- **Explanation:** Retinacular vessels run under capsule; displaced neck # disrupts them → AVN.
- **Trend:** Very high; links anatomy → AVN.
- **Clinical:** Explains Garden-type nonunion/AVN.
- **Examiner Tip:** MCFA, not femoral artery, not foveal.
- **Ref:** Gray's, hip.

## 7. Knee Joint ⭐⭐⭐⭐⭐ (Anatomy)
- **Notes:** Tibiofemoral + patellofemoral. ACL (ant drawer, Lachman) prevents ant tibial translation; PCL (post drawer) prevents post translation. Menisci = medial (C, firm) / lateral (O). Locking (screw-home, medial rotation of femur) needs popliteus to unlock. Nerve: infrapatellar branch of saphenous + articular branches.
- **Rapid Rev:** ACL = ant, "turn & pivot"; PCL = post (dashboard). Locking = medial femoral rotation; unlocking = popliteus.
- **SBA:** Unlocking of knee is by: **popliteus muscle**.
- **MCQ:** Medial meniscus is more commonly injured because: **it is fixed to tibial collateral ligament**.
- **Explanation:** Medial meniscus attached to MCL → less mobile → torn more.
- **Trend:** Very high; cruciate/meniscus + popliteus.
- **Clinical:** ACL reconstruction, meniscectomy.
- **Examiner Tip:** Locking = medial rotation; popliteus UNLOCKS.
- **Ref:** Gray's, knee.

## 8. Shoulder Joint ⭐⭐⭐⭐ (Anatomy)
- **Notes:** Ball-and-socket, most mobile, least stable. Rotator cuff = SItS (Supraspinatus, Infraspinatus, Teres minor, Subscapularis) — holds head in glenoid. Axillary nerve (C5–C6) winds round surgical neck → deltoid loss ("square shoulder"), loss of abduction first 15°.
- **Rapid Rev:** "SITS": Supraspinatus (abducts 0–15), Infraspinatus (ext rot), Teres minor (ext rot), Subscapularis (int rot). Axillary n. = surgical neck #.
- **SBA:** Nerve injured in surgical neck # humerus: **axillary nerve (C5–C6)**.
- **MCQ:** First 15° abduction is by: **supraspinatus**.
- **Explanation:** Supraspinatus initiates abduction; deltoid continues but needs cuff for stability.
- **Trend:** High; nerve + cuff.
- **Clinical:** Fracture neck humerus, shoulder dislocation (axillary n.).
- **Examiner Tip:** Axillary = surgical neck; radial = spiral groove; not the same.
- **Ref:** Gray's / Snell.

## 9. Skeletal Muscle Contraction ⭐⭐⭐⭐ (Physiology)
- **Notes:** Sliding filament: Ca²⁺ binds troponin-C → tropomyosin shifts → myosin cross-bridges bind actin → power stroke. Excitation–contraction coupling: AP → T-tubule → RyR releases SR Ca²⁺. Relaxation = Ca²⁺ pumped back (SERCA), ATP needed.
- **Rapid Rev:** "Ca²⁺ is the trigger." Rigor mortis = ATP depletion, cross-bridges stuck.
- **SBA:** Calcium binds to: **troponin C**.
- **MCQ:** Rigor mortis is due to: **loss of ATP → persistent actin-myosin binding**.
- **Explanation:** Without ATP, myosin cannot detach → stiffness.
- **Trend:** High; basic physio favourite.
- **Clinical:** Malignant hyperthermia (RYR1), neuroleptic malignant syndrome.
- **Examiner Tip:** Troponin C (not tropomyosin, not actin).
- **Ref:** Guyton ch. Muscle; Ganong.

## 10. Calcium Homeostasis ⭐⭐⭐⭐⭐ (Physiology)
- **Notes:** PTH ↑ Ca²⁺ (bone resorption, renal reabsorption, ↑ 1α-hydroxylase → calcitriol). Calcitriol (1,25-OH vit D) ↑ gut Ca²⁺/PO₄ absorption. Calcitonin (C-cells, thyroid) ↓ Ca²⁺. Normal Ca²⁺ ~8.5–10.5 mg/dL; ionised is active.
- **Rapid Rev:** PTH = "bone kidney gut"↑Ca; Calcitonin opposes; Vit D = gut absorption.
- **SBA:** Most important regulator of plasma Ca²⁺: **PTH**.
- **MCQ:** 1,25-dihydroxyvitamin D is formed in: **kidney (proximal tubule)**.
- **Explanation:** Liver 25-hydroxylation, kidney 1α-hydroxylation.
- **Trend:** Very high; bone-metabolism link.
- **Clinical:** Hypoparathyroidism (Tetany, Chvostek/Trousseau), hyperCa (stones/bones/groans).
- **Examiner Tip:** Vitamin D activated in KIDNEY, not skin, not liver final step.
- **Ref:** Guyton / Ganong, endocrine.

## 11. Bone Remodelling ⭐⭐⭐⭐ (Physiology)
- **Notes:** Osteoblasts form bone (osteoid, type I collagen); osteoclasts resorb (multinucleate, RANK-L from osteoblast → RANK on osteoclast). OPG inhibits RANKL. Wolff's law: bone adapts to stress. Coupling = remodelling units.
- **Rapid Rev:** RANKL→RANK = resorption; OPG = brake. Wolff = form follows function.
- **SBA:** Osteoclast formation is stimulated by: **RANKL**.
- **MCQ:** Wolff's law states: **bone architecture remodels according to mechanical stress**.
- **Explanation:** Mechanical loading directs remodelling; immobilisation → resorption.
- **Trend:** High; osteoporosis/bisphosphonate link.
- **Clinical:** Osteoporosis (anti-RANKL denosumab), immobilisation osteoporosis.
- **Examiner Tip:** OPG = antagonist of RANKL.
- **Ref:** Guyton.

## 12. Nerve Action Potential & Conduction ⭐⭐⭐ (Physiology)
- **Notes:** Depolarisation = Na⁺ influx (voltage-gated Na channels); repolarisation = K⁺ efflux. Myelinated fibres saltatory conduction (nodes of Ranvier) → faster. Demyelination (MS, GBS) → slowed/blocked conduction, ↓ velocity.
- **Rapid Rev:** Saltatory = jumping node→node. Demyelination = ↓ velocity, not ↓ amplitude primarily.
- **SBA:** Saltatory conduction occurs in: **myelinated nerve fibres**.
- **MCQ:** In demyelination, what is primarily reduced: **conduction velocity**.
- **Explanation:** Saltatory conduction lost → slow impulse.
- **Trend:** Moderate; basic neurophysio.
- **Clinical:** Guillain-Barré, MS.
- **Examiner Tip:** Demyelination → velocity ↓ (amplitude may be preserved early).
- **Ref:** Ganong.

## 13. Cartilage Nutrition ⭐⭐⭐ (Physiology)
- **Notes:** Articular cartilage is avascular, aneural, alymphatic. Nutrition by diffusion from synovial fluid during joint loading/unloading (pump mechanism). Chondrocytes in lacunae, matrix = type II collagen + proteoglycan (aggrecan, GAGs).
- **Rapid Rev:** "Cartilage feeds by diffusion from synovium." No vessels = poor healing.
- **SBA:** Articular cartilage receives nutrition mainly from: **synovial fluid (diffusion)**.
- **MCQ:** Cartilage matrix predominantly contains: **type II collagen + proteoglycans**.
- **Explanation:** Avascular → limited repair; basis of OA.
- **Trend:** Moderate; OA link.
- **Clinical:** OA (cartilage loss), cartilage injuries.
- **Examiner Tip:** Type II (cartilage), Type I (bone/tendon/skin).
- **Ref:** Guyton.

## 14. Collagen Types & Synthesis ⭐⭐⭐⭐⭐ (Biochemistry)
- **Notes:** Type I (bone, tendon, skin, cornea) — deficiency = Osteogenesis imperfecta (brittle bones, blue sclerae). Type II (cartilage). Type III (blood vessels, granulation, skin — Ehlers-Danlos/vascular). Type IV (basement membrane). Synthesis: preprocollagen → procollagen (hydroxyproline/hydroxylysine need Vit C = prolyl/lysyl hydroxylase) → triple helix → secretion → cleavage → fibrils.
- **Rapid Rev:** "Be (I) a BONE, Tendon, Skin." Vit C needed for hydroxylation; deficiency = scurvy.
- **SBA:** Osteogenesis imperfecta is due to defect in: **type I collagen**.
- **MCQ:** Hydroxylation of proline/lysine in collagen requires: **vitamin C (ascorbate)**.
- **Explanation:** No Vit C → defective collagen → scurvy (bleeding gums, poor healing).
- **Trend:** Very high; OI + scurvy.
- **Clinical:** OI, scurvy, Ehlers-Danlos.
- **Examiner Tip:** OI = Type I (not II). Scurvy = no Vit C hydroxylation.
- **Ref:** Lippincott Biochem; Robbins.

## 15. Vitamin D Metabolism ⭐⭐⭐⭐⭐ (Biochemistry)
- **Notes:** Skin 7-dehydrocholesterol → cholecalciferol (D3) via UV; diet D2/D3 → liver 25-OH (storage) → kidney 1α-OH → 1,25-(OH)₂D (active). Deficiency in children = rickets (wide epiphyses, rachitic rosary, bowing); adults = osteomalacia (bone pain, Looser's zones). Breastfed infants in BD need supplementation.
- **Rapid Rev:** Rickets = children (growth plate open); Osteomalacia = adults (defective mineralisation).
- **SBA:** Active form of vitamin D: **1,25-dihydroxycholecalciferol**.
- **MCQ:** Rickets is characterised by: **widened epiphyses & bowing of long bones**.
- **Explanation:** Unmineralised osteoid at growth plate → deformity.
- **Trend:** Very high; Bangladesh endemic.
- **Clinical:** Nutritional rickets (BD common), renal osteodystrophy.
- **Examiner Tip:** Rickets = children; Osteomalacia = adults (same deficiency).
- **Ref:** Lippincott.

## 16. Gout ⭐⭐⭐⭐ (Biochemistry)
- **Notes:** Urate metabolism: purine breakdown → xanthine → uric acid (xanthine oxidase). Hyperuricaemia → monosodium urate crystals in joint (negatively birefringent, needle-shaped under polarised light). Allopurinol/febuxostat inhibit xanthine oxidase; probenecid ↑ excretion; colchicine/NSAIDs acute.
- **Rapid Rev:** Gout crystals = NEGATIVELY birefringent needles. Pseudogout (CPP) = positively birefringent rhomboids.
- **SBA:** Gout crystals under polarised light are: **negatively birefringent, needle-shaped**.
- **MCQ:** Xanthine oxidase inhibitor used in gout: **allopurinol**.
- **Explanation:** Allopurinol reduces uric acid production.
- **Trend:** High; crystal differentiation.
- **Clinical:** Podagra (1st MTP), tophi, renal stones.
- **Examiner Tip:** Gout = NEGATIVE; Pseudogout (CPPD) = POSITIVE birefringence.
- **Ref:** Lippincott; Robbins.

## 17. Fracture Healing ⭐⭐⭐⭐⭐ (Pathology)
- **Notes:** Stages: haematoma → inflammatory (week 1) → soft callus (fibrocartilage, weeks 2–3) → hard callus (woven bone, weeks 4–12) → remodelling (months–years, lamellar). Primary (direct) healing with rigid fixation (no callus). Delayed union >expected; non-union (no healing, pseudoarthrosis); malunion.
- **Rapid Rev:** Factors delaying: infection, poor blood, distraction, smoking, NSAIDs, radiotherapy, malnutrition.
- **SBA:** Hard callus is composed of: **woven bone**.
- **MCQ:** Which delays fracture healing: **infection / smoking / NSAIDs / distraction** (all EXCEPT good reduction).
- **Explanation:** Infection & instability are top causes of non-union.
- **Trend:** Very high; healing + non-union causes.
- **Clinical:** Atrophic vs hypertrophic non-union.
- **Examiner Tip:** Primary healing = NO callus (rigid compression plate).
- **Ref:** Robbins, bone repair.

## 18. Osteomyelitis ⭐⭐⭐⭐⭐ (Pathology)
- **Notes:** Acute haematogenous (children) → femur/distal femur metaphysis (slow flow, metaphyseal loops). S. aureus #1. Neonates: Group B strep, E. coli. Sickle cell: Salmonella. Chronic → sequestrum (dead bone) + involucrum (new shell) + sinus. Brodie's abscess = subacute localised.
- **Rapid Rev:** "Metaphysis in kids." Sequestrum = dead bone; Involucrum = living shell.
- **SBA:** Most common organism in acute haematogenous osteomyelitis: **S. aureus**.
- **MCQ:** In sickle-cell disease osteomyelitis is commonly due to: **Salmonella**.
- **Explanation:** Vaso-occlusion + infarcted marrow → Salmonella favoured.
- **Trend:** Very high; organism + sequestrum.
- **Clinical:** Chronic osteomyelitis, diabetic foot osteo.
- **Examiner Tip:** Sequestrum = dead bone (not involucrum).
- **Ref:** Robbins; Lippincott Micro.

## 19. Bone Tumours Overview ⭐⭐⭐⭐⭐ (Pathology)
- **Notes:** Osteosarcoma = metaphysis, sunburst, Codman triangle, young. Chondrosarcoma = pelvis/shoulder, cartilage matrix, adults. Ewing's = diaphysis, onion-skin, t(11;22), <20 yr. Giant-cell = epiphysis, soap-bubble, 20–40 yr. Metastasis = most common malignant bone tumour (prostate = blastic, breast/lung/thyroid = lytic).
- **Rapid Rev:** Osteo = metaphysis/sunburst; Ewing = diaphysis/onion; GCT = epiphysis/soap-bubble.
- **SBA:** Onion-skin periosteal reaction suggests: **Ewing's sarcoma**.
- **MCQ:** Most common malignant bone tumour overall: **metastasis**.
- **Explanation:** Metastases outnumber primary malignancies.
- **Trend:** Very high; imaging sign → diagnosis.
- **Clinical:** "Coda triangle," lung mets in osteosarcoma.
- **Examiner Tip:** Osteosarcoma = METAPHYSIS; Ewing = DIAPHYSIS.
- **Ref:** Robbins, bone tumours.

## 20. Avascular Necrosis ⭐⭐⭐⭐ (Pathology)
- **Notes:** Ischaemic death of bone marrow + trabeculae → collapse. Common sites: femoral head, scaphoid proximal pole, talus, femoral condyle. Causes: #/dislocation (NOF), steroids, alcohol, sickle cell, Caisson, Gaucher. MRI = earliest/sensitive.
- **Rapid Rev:** "ASEPTIC": Alcohol, Steroids, Trauma, Idiopathic, Caisson, Lupus/Legg, Sickle.
- **SBA:** Investigation of choice for early AVN femoral head: **MRI**.
- **MCQ:** Most common cause of AVN of femoral head: **fracture neck femur / steroids**.
- **Explanation:** Disruption of MCFA retinacular vessels.
- **Trend:** High; investigation-of-choice.
- **Clinical:** Steroid-induced AVN in lupus/transplant.
- **Examiner Tip:** X-ray normal early → MRI is gold standard.
- **Ref:** Robbins; Apley.

## 21. NSAIDs ⭐⭐⭐⭐⭐ (Pharmacology)
- **Notes:** Inhibit cyclo-oxygenase → ↓ prostaglandins. COX-1 (housekeeping: gastric mucosa, platelets, kidney) vs COX-2 (inflammation). Aspirin irreversibly inhibits platelet COX-1 (anti-platelet). GI bleed, renal impairment, Reye's syndrome (aspirin in children/viral). COX-2 inhibitors (celecoxib) spare GI but ↑ CV risk.
- **Rapid Rev:** Aspirin = irreversible; Reye's = aspirin + viral in kids; COX-2 = GI-safe, CV-risk.
- **SBA:** Reye's syndrome is associated with: **aspirin in children with viral illness**.
- **MCQ:** Aspirin's antiplatelet effect is due to: **irreversible COX-1 inhibition**.
- **Explanation:** Permanent platelet COX blockade until new platelets form (~7–10 d).
- **Trend:** Very high; Reye's + COX.
- **Clinical:** Post-op analgesia, VTE prophylaxis adjunct.
- **Examiner Tip:** Reye's = aspirin (not paracetamol).
- **Ref:** Katzung.

## 22. Bisphosphonates ⭐⭐⭐⭐ (Pharmacology)
- **Notes:** Pyrophosphate analogues; bind bone hydroxyapatite, ingested by osteoclasts → apoptosis. Used in osteoporosis, Paget's, metastases (↓ skeletal events), hyperCa. Adverse: oesophageal irritation (take upright), osteonecrosis of jaw (ONJ), atypical subtrochanteric femur fractures, hypocalcaemia/AVN of jaw.
- **Rapid Rev:** "Alendronate weekly, upright, wait 30 min." ONJ + atypical femur # = rare but tested.
- **SBA:** Atypical femoral fracture is a known adverse effect of: **bisphosphonates**.
- **MCQ:** Bisphosphonates act by: **inhibiting osteoclast-mediated bone resorption**.
- **Explanation:** Toxic to osteoclasts → net bone gain.
- **Trend:** High; ONJ + atypical fracture (now in exams).
- **Clinical:** Osteoporosis, Paget's, myeloma bone disease.
- **Examiner Tip:** ONJ (not AVN of hip) is the classical oral bisphos complication.
- **Ref:** Katzung.

## 23. Local Anaesthetics / Spinal / Epidural ⭐⭐⭐ (Pharmacology)
- **Notes:** Block Na⁺ channels (use-dependent) → no AP. Esters (procaine, cocaine) metabolised by plasma cholinesterase; amides (lidocaine, bupivacaine, ropivacaine) by liver. Spinal = intrathecal (subarachnoid), single shot, sympathetic block first. Epidural = epidural space, catheter. Bupivacaine cardiotoxic.
- **Rapid Rev:** Esters = -caine with ONE i (procaine); Amides = TWO i (lidocaine). Spinal → hypotension (sympathetic).
- **SBA:** Most cardiotoxic local anaesthetic: **bupivacaine**.
- **MCQ:** Spinal anaesthesia causes hypotension due to: **sympathetic blockade**.
- **Explanation:** Sympathetic tone lost → vasodilatation → hypotension.
- **Trend:** Moderate; ortho OT relevance.
- **Clinical:** TIVA/regional for joint replacement; tourniquet.
- **Examiner Tip:** Tourniquet = ischaemia; LA toxicity = CNS then cardiac.
- **Ref:** Katzung.

## 24. Orthopaedic Infections (Microbiology) ⭐⭐⭐⭐⭐ (Microbiology)
- **Notes:** S. aureus (incl. MRSA) = #1 in osteomyelitis, septic arthritis, implant infection. Neonatal osteo: GBS, E. coli, S. aureus. Sickle cell: Salmonella. TB spine (Pott's) = M. tuberculosis. Biofilm on implants protects bacteria (needs debridement + spacer + ABx).
- **Rapid Rev:** "Staph rules ortho." Septic arthritis in sexually active = N. gonorrhoeae.
- **SBA:** Most common organism in septic arthritis: **S. aureus**.
- **MCQ:** Implant-related infection is protected by: **biofilm**.
- **Explanation:** Biofilm = recalcitrant; requires hardware removal.
- **Trend:** Very high; organism + biofilm.
- **Clinical:** MRSA, diabetic foot, TB spine.
- **Examiner Tip:** Gonococcal septic arthritis = young sexually active (not Staph in that niche).
- **Ref:** Lippincott Microbiology.

## 25. Prophylactic Antibiotics in Ortho ⭐⭐⭐⭐ (Microbiology)
- **Notes:** Single pre-incision dose cefazolin (cephalosporin) 1st gen covers MSSA; allergy → clindamycin/vancomycin (MRSA cover). Given within 60 min before incision. Impregnated bone cement (antibiotic-loaded, e.g., gentamicin/vancomycin) for revision/septic.
- **Rapid Rev:** Cefazolin 1g IV pre-op. Cement = local ABx delivery.
- **SBA:** Prophylactic antibiotic of choice for clean ortho implant surgery: **cefazolin**.
- **MCQ:** Antibiotic-loaded bone cement is used to: **deliver local high-dose ABx & prevent biofilm**.
- **Explanation:** Local elution beats systemic for biofilm prevention.
- **Trend:** High; OT protocol.
- **Clinical:** Joint replacement, ORIF.
- **Examiner Tip:** Cefazolin (not cephalexin oral) for surgical prophylaxis.
- **Ref:** Lippincott; AAOS guidelines.

## 26. Shock ⭐⭐⭐⭐
- **Notes:** Hypovolaemic (haemorrhage/trauma) most common in ortho; cardiogenic; distributive (septic/anaphylactic/neurogenic); obstructive (tension PTx, Tamponade, PE). Class IV haemorrhage >40% blood volume → shock.
- **Rapid Rev:** "HIPP" = Hypovolaemic, Cardiogenic, Distributive, Obstructive. Shock = inadequate tissue perfusion.
- **SBA:** Most common type of shock in trauma: **hypovolaemic**.
- **MCQ:** Class IV haemorrhage corresponds to blood loss: **>2000 mL (>40%)**.
- **Explanation:** Replace intravascular volume (crystalloid then blood).
- **Trend:** High; classification stems.
- **Clinical:** Polytrauma, pelvic/# femur haemorrhage.
- **Examiner Tip:** Neurogenic shock = bradycardia + warm (not cold) skin.
- **Ref:** Bailey & Love, ch. Shock.

## 27. Fluid & Electrolyte ⭐⭐⭐⭐
- **Notes:** Burns Parkland = 4 mL × kg × %TBSA over 24 h, HALF in first 8 h. Hyperkalaemia ECG: peaked T, widened QRS, sine wave → arrhythmias; treat Ca²⁺ gluconate, insulin+Dextrose, nebulised salbutamol.
- **Rapid Rev:** Parkland: 4-2-1? No — 4 mL/kg/%TBSA. HyperK = peaked T.
- **SBA:** Parkland formula fluid for 50 kg, 40% burn in first 8 h: **4000 mL** (4×50×40=8000/24h; half=4000 in 8h).
- **MCQ:** Earliest ECG sign of hyperkalaemia: **peaked T waves**.
- **Explanation:** K⁺ shifts resting membrane potential.
- **Trend:** High; numerical Parkland tested.
- **Clinical:** Burns, crush injury (rhabdo→hyperK).
- **Examiner Tip:** Half the calculated 24h volume is given in the FIRST 8 h from time of burn.
- **Ref:** Schwartz, Burns.

## 28. Wound Healing ⭐⭐⭐⭐
- **Notes:** Primary (intentional, clean <8–12 h); secondary (granulation, open, e.g., pressure sore); tertiary/delayed primary (contaminated then closed). Impaired by infection, DM, steroids, ischaemia, malnutrition, smoking, radiation.
- **Rapid Rev:** Infection = #1 cause of delayed healing. Vitamin C/protein needed.
- **SBA:** Healing by secondary intention occurs in: **open/contaminated wounds (e.g., pressure ulcer)**.
- **MCQ:** Which most impairs healing: **infection** (vs clean closure, good nutrition).
- **Explanation:** Bacteria → persistent inflammation → no maturation.
- **Trend:** High; factors stems.
- **Clinical:** Diabetic foot, dehisced laparotomy.
- **Examiner Tip:** "Secondary" = granulation fills; not primary suture.
- **Ref:** Bailey & Love.

## 29. Tetanus ⭐⭐⭐⭐⭐
- **Notes:** Clostridium tetani spore; tetanospasmin blocks inhibitory interneurons (GABA/glycine) → sustained muscle spasm/risus sardonicus, opisthotonos, trismus (lockjaw). Prophylaxis: active TT + passive TIG for dirty wounds. Rx: wound debridement, TIG, metronidazole, benzodiazepines, airway.
- **Rapid Rev:** Toxin blocks INHIBITION → spasm. TIG = passive (immediate), TT = active.
- **SBA:** Tetanus toxin acts by: **blocking inhibitory neurotransmitters (GABA/glycine)**.
- **MCQ:** Passive immunisation in tetanus: **Tetanus Immunoglobulin (TIG)**.
- **Explanation:** TIG neutralises unbound toxin; cannot reverse bound toxin.
- **Trend:** Very high; mechanism + prophylaxis.
- **Clinical:** Road-traffic/open wounds (BD common).
- **Examiner Tip:** TIG (human) not ATS if available; "lockjaw" = trismus.
- **Ref:** Bailey & Love; Lippincott Micro.

## 30. Gas Gangrene ⭐⭐⭐⭐
- **Notes:** Clostridium perfringens (α-toxin phospholipase C) → myonecrosis, crepitus, foul serosanguinous discharge, systemic toxicity, haemolysis. Rx: urgent wide debridement/amputation + penicillin+clindamycin + hyperbaric O₂.
- **Rapid Rev:** Crepitus + foul smell = gas gangrene. HBOT adjunct.
- **SBA:** Causative organism of gas gangrene: **Clostridium perfringens**.
- **MCQ:** Crepitus in a traumatic wound suggests: **gas-forming infection (C. perfringens)**.
- **Explanation:** Gas from fermentation in devitalised muscle.
- **Trend:** High; organism + crepitus.
- **Clinical:** War/RTA crush injuries.
- **Examiner Tip:** Gas gangrene = muscle (myonecrosis), not just skin.
- **Ref:** Bailey & Love.

## 31. Blood Transfusion ⭐⭐⭐
- **Notes:** Indication stable Hb <7–8 g/dL. Reactions: acute haemolytic (ABO, fever+hemoglobinuria, DIC), febrile non-haemolytic (most common), allergic, TRALI (donor anti-leukocyte → pulmonary oedema), TACO (volume), GVHD (irradiated blood for immunocompromised).
- **Rapid Rev:** TRALI = donor antibodies; TACO = volume overload.
- **SBA:** Most common transfusion reaction: **febrile non-haemolytic**.
- **MCQ:** TRALI is caused by: **donor anti-leukocyte antibodies**.
- **Explanation:** Neutrophil priming → pulmonary capillary leak.
- **Trend:** Moderate; reaction identification.
- **Clinical:** Polytrauma, major ortho (spine).
- **Examiner Tip:** TRALI = donor; TACO = recipient volume.
- **Ref:** Sabiston.

## 32. Polytrauma / ATLS ⭐⭐⭐⭐⭐
- **Notes:** Primary survey ABCDE; C-spine immobilisation; oxygenation; control haemorrhage; assess disability (GCS); exposure. Damage-control surgery for unstable. "Treat the greatest threat to life first."
- **Rapid Rev:** A irway+C-spine, B reathing, C irculation, D isability, E xposure.
- **SBA:** First step in ATLS primary survey: **airway with cervical-spine control**.
- **MCQ:** In polytrauma, priority is: **life-threatening airway/breathing/bleeding first**.
- **Explanation:** Algorithm = resuscitation before definitive fixation.
- **Trend:** Very high; trauma stems.
- **Clinical:** RTA, fall from height.
- **Examiner Tip:** Pelvic binder for unstable pelvic # before X-ray.
- **Ref:** ATLS Manual.

## 33. Compartment Syndrome ⭐⭐⭐⭐⭐
- **Notes:** ↑ interstitial pressure > perfusion → ischaemia. 5 Ps: Pain (disproportionate), Pain on passive stretch (EARLY), Paraesthesia, Pallor, Pulselessness & Paralysis (LATE). Dx: clinical + compartment pressure >30 mmHg. Rx: urgent fasciotomy.
- **Rapid Rev:** Pain + passive stretch = EARLY. Pulselessness = LATE (don't wait!).
- **SBA:** Earliest reliable sign of compartment syndrome: **pain on passive stretch**.
- **MCQ:** Late sign of compartment syndrome: **pulselessness / paralysis**.
- **Explanation:** Nerves/muscle ischaemia precede pulse loss.
- **Trend:** Very high; classic trap (pulselessness is late).
- **Clinical:** Tibial #, forearm (Volkmann), casts too tight, reperfusion.
- **Examiner Tip:** Absent pulse does NOT mean early — it's late.
- **Ref:** Bailey & Love; Apley.

## 34. Burns ⭐⭐⭐⭐
- **Notes:** Rule of nines (adult): head 9, each arm 9, ant trunk 18, post trunk 18, each leg 18, perineum 1. Lund-Browder for children. Parkland resuscitation. Circumferential full-thickness → escharotomy for perfusion/ventilation.
- **Rapid Rev:** Adult: 9-18-18-18-18-1. Child: head bigger (18), leg smaller.
- **SBA:** Total body surface in rule of nines for both legs (adult): **36%**.
- **MCQ:** Indication for escharotomy: **circumferential full-thickness burn compromising circulation**.
- **Explanation:** Eschar acts as tourniquet.
- **Trend:** High; rule-of-nines numerical.
- **Clinical:** Electrical/flame burns.
- **Examiner Tip:** Use Lund-Browder in children (rule of nines overestimates head).
- **Ref:** Schwartz, Burns.

## 35. Soft-Tissue Tumours ⭐⭐⭐
- **Notes:** Lipoma = benign, soft, mobile. Sarcoma = deep, >5 cm, growing, painful, fixed; staging by size/depth/grade/metastasis. Biopsy principle: incisional, longitudinal, do NOT cross compartments, plan with surgeon.
- **Rapid Rev:** "Deep + >5 cm + painful" → suspect sarcoma.
- **SBA:** Suspicious soft-tissue mass should be biopsied by: **incisional biopsy planned with the treating surgeon**.
- **MCQ:** Benign soft-tissue tumour most common: **lipoma**.
- **Explanation:** Bad biopsy can upstage/worsen resection.
- **Trend:** Moderate; biopsy principle tested.
- **Clinical:** Extremity masses.
- **Examiner Tip:** NEVER excise a suspected sarcoma widely without biopsy plan.
- **Ref:** Schwartz; Camp.

## 36. Thyroid / Parathyroid ⭐⭐⭐
- **Notes:** Primary hyperparathyroidism → ↑ PTH → hypercalcaemia (stones, bones, groans, psychiatric moans), brown tumours of bone (osteoclastoma-like), osteoporosis. #1 cause = solitary adenoma.
- **Rapid Rev:** Brown tumour = giant-cell reparative granuloma in hyperPTH.
- **SBA:** Brown tumour of bone is seen in: **hyperparathyroidism**.
- **MCQ:** 'Stones, bones, groans' describe: **hypercalcaemia of hyperparathyroidism**.
- **Explanation:** PTH ↑ bone resorption → cysts/brown tumours.
- **Trend:** Moderate; bone link.
- **Clinical:** Renal stones, pathological #.
- **Examiner Tip:** Brown tumour = NOT giant-cell tumour of tendon sheath.
- **Ref:** Schwartz, Endocrine.

## 37. Acute Limb Ischaemia ⭐⭐⭐⭐
- **Notes:** 6 Ps: Pain, Pulseless, Pallor, Paraesthesia, Paralysis, Perishing cold. Rutherford categories (I viable, IIa/b threatened, III irreversible). Embolus (AF, saddle) vs in-situ thrombosis. Rx: heparin, embolectomy/thrombectomy.
- **Rapid Rev:** 6 Ps (add Perishing cold). Embolus = sudden, AF source.
- **SBA:** Sudden painful pulseless leg in AF: **acute arterial embolus**.
- **MCQ:** Most common source of arterial embolus: **cardiac (atrial fibrillation)**.
- **Explanation:** Embolus lodges at bifurcation (common femoral/popliteal).
- **Trend:** High; 6 Ps.
- **Clinical:** Acute popliteal embolism.
- **Examiner Tip:** Paralysis = irreversible if late (Rutherford III).
- **Ref:** Rutherford; Bailey & Love.

## 38. DVT / PE ⭐⭐⭐⭐⭐
- **Notes:** Virchow's triad: stasis, endothelial injury, hypercoagulability. Prophylaxis: LMWH (enoxaparin), mechanical (stockings, IPC), early mobilisation. Rx: anticoagulation; PE = chest pain, dyspnoea, hypoxia, Wells score.
- **Rapid Rev:** Ortho # (esp. hip/knee, pelvis) = high DVT risk. LMWH post-op.
- **SBA:** Prophylaxis of DVT after ortho surgery: **LMWH + early mobilisation + compression**.
- **MCQ:** Virchow's triad includes: **stasis, endothelial injury, hypercoagulability**.
- **Explanation:** Immobility + surgery → stasis + hypercoagulability.
- **Trend:** Very high; prophylaxis stems.
- **Clinical:** THR/TKR, pelvis/# femur.
- **Examiner Tip:** LMWH, not aspirin, is standard VTE prophylaxis.
- **Ref:** Bailey & Love; AAOS.

## 39. Amputation ⭐⭐⭐
- **Notes:** Indications: ischaemia (PVD), trauma (unsalvageable), tumour, infection (gas gangrene), congenital. Levels: above/below knee, Syme's, through-knee. Phantom limb pain common. Myoplastic closure.
- **Rapid Rev:** Below-knee (BK) better functional outcome than AK.
- **SBA:** Most common level of lower-limb amputation: **below-knee (transtibial)**.
- **MCQ:** Phantom limb sensation is: **common and normal post-amputation**.
- **Explanation:** Cortical remap → perceived sensation.
- **Trend:** Moderate; levels.
- **Clinical:** Diabetic foot, vascular.
- **Examiner Tip:** BK preserves knee → better prosthesis function.
- **Ref:** Sabiston.

## 40. Gait & Limp ⭐⭐⭐⭐⭐
- **Notes:** Trendelenburg (gluteus medius weakness → contralateral pelvic drop; test: stand on one leg). Antalgic (pain → short stance). Short-leg (circumduction). Spastic (hemiplegic). Waddling (proximal myopathy/DMD).
- **Rapid Rev:** Trendelenburg +ve = pelvic drop on unsupported side.
- **SBA:** Positive Trendelenburg test indicates weakness of: **gluteus medius**.
- **MCQ:** Limp with pain relieved by rest = **antalgic limp**.
- **Explanation:** Gluteus medius stabilises pelvis in single-leg stance.
- **Trend:** Very high; gait test.
- **Clinical:** DDH, Perthes, hip OA, polio.
- **Examiner Tip:** Trendelenburg test = STAND on affected leg, pelvis drops on normal side.
- **Ref:** Apley.

## 41. Peripheral Nerve Injury ⭐⭐⭐⭐⭐
- **Notes:** Seddon: neurapraxia (conduction block, recovers), axonotmesis (axon interrupted, Wallerian, regenerates 1 mm/day), neurotmesis (transection). Sunderland 1–5. Tinel = regenerating nerve (tingling distal to percussion).
- **Rapid Rev:** Neurapraxia = temporary; neurotmesis = needs surgery.
- **SBA:** Conduction block without axonal disruption: **neurapraxia**.
- **MCQ:** Rate of peripheral nerve regeneration: **~1 mm/day**.
- **Explanation:** Axonotmesis regenerates along intact endoneurium.
- **Trend:** Very high; classification.
- **Clinical:** Saturday-night palsy (radial), bracelet injury (ulnar).
- **Examiner Tip:** Neurapraxia recovers fully (e.g., transient foot drop).
- **Ref:** Bailey & Love.

## 42. Hand Infections ⭐⭐⭐⭐
- **Notes:** Felon (pulp space), paronychia (nail fold), flexor tenosynovitis (Kanavel: finger held flexed, uniform swelling, tenderness along sheath, pain on extension), thenar/web-space space abscess.
- **Rapid Rev:** Kanavel's 4 signs = tenosynovitis.
- **SBA:** Flexor tenosynovitis is suggested by: **Kanavel's signs (flexed posture + tenderness along tendon)**.
- **MCQ:** Most common hand infection: **paronychia**.
- **Explanation:** Sheath infection can destroy tendon rapidly.
- **Trend:** High; Kanavel signs.
- **Clinical:** Diabetic, penetrating injury.
- **Examiner Tip:** Flexor tenosynovitis = surgical emergency (not just antibiotics).
- **Ref:** Bailey & Love.

## 43. Skin Flaps & Grafts ⭐⭐⭐
- **Notes:** Split-thickness graft (epidermis + partial dermis; donor = thigh; meshed). Full-thickness (better cosmesis; small defects). Myocutaneous/rotational flap = vascularised tissue for coverage (e.g., trauma, pressure sore, tumour).
- **Rapid Rev:** STSG takes on granulating bed; flap carries its own blood supply.
- **SBA:** Split-thickness skin graft includes: **epidermis + part of dermis**.
- **MCQ:** Flap differs from graft in having: **its own blood supply**.
- **Explanation:** Grafts rely on recipient bed; flaps are pedicled/free.
- **Trend:** Moderate; flap vs graft.
- **Clinical:** Trauma coverage, decubitus.
- **Examiner Tip:** Free flap = microvascular anastomosis.
- **Ref:** Schwartz, Plastic.

## 44. Triage & Disaster ⭐⭐
- **Notes:** Simple triage: Red = immediate (life-threatening, salvageable), Yellow = delayed, Green = minor (walking wounded), Black = deceased/expectant.
- **Rapid Rev:** START: Resp >30 / nil → red/black; perfusion/mental → sort.
- **SBA:** Immobile breathing patient after disaster with no radial pulse: **red (immediate)** or black if apnoeic after airway.
- **MCQ:** Walking wounded are tagged: **green**.
- **Explanation:** Prioritise salvageable life-threatening.
- **Trend:** Low; mass-casualty.
- **Clinical:** RTA pile-ups, earthquakes.
- **Examiner Tip:** Black = deceased/expectant, not "least urgent" misread.
- **Ref:** ATLS.

## 45. Sepsis & SIRS ⭐⭐⭐⭐
- **Notes:** SIRS ≥2: T>38 or <36, HR>90, RR>20 (or PaCO₂<32), WCC>12 or <4. Sepsis = SIRS + suspected infection. qSOFA: RR≥22, altered mentation, SBP≤100. Septic shock = refractory hypotension.
- **Rapid Rev:** SIRS needs 2 criteria. qSOFA = bedside quick screen.
- **SBA:** SIRS is diagnosed by at least: **2 of the four criteria**.
- **MCQ:** qSOFA includes: **RR ≥22, altered mentation, SBP ≤100**.
- **Explanation:** Sepsis bundles: cultures, ABx, fluids.
- **Trend:** High; definitions.
- **Clinical:** Post-op, UTI, pneumonia, wound sepsis.
- **Examiner Tip:** SIRS can occur WITHOUT infection (e.g., trauma, pancreatitis).
- **Ref:** Surviving Sepsis.

*Refs: Apley · Campbell · Rockwood & Green · AO Principles · Robbins · Miller's Review*

## 46. Femoral Neck Fracture ⭐⭐⭐⭐⭐
- **Notes:** Intracapsular; Garden I–IV (I incomplete, II complete non-displaced, III partial displacement, IV full displacement). Displaced → disrupted MCFA retinacular vessels → AVN + non-union. Rx: <60 ORIF (cannulated screws); >65 arthroplasty (hemi/total).
- **Rapid Rev:** Garden ↑ = displacement ↑ = AVN ↑. Intracapsular = precarious blood.
- **SBA:** Most common complication of displaced intracapsular neck #: **avascular necrosis**.
- **MCQ:** Garden Type IV = **complete displacement**.
- **Explanation:** Capsular vessels torn → head ischaemia.
- **Trend:** Very high; Garden + AVN.
- **Clinical:** Elderly fall, osteoporosis.
- **Examiner Tip:** Intracapsular (Garden) = AVN risk; intertrochanteric = union good.
- **Ref:** Apley; Rockwood.

## 47. Intertrochanteric Fracture ⭐⭐⭐⭐⭐
- **Notes:** Extracapsular; rich blood supply → unites well. Evans classification (I stable, II unstable). Rx: Dynamic Hip Screw (DHS) / intramedullary nail (PFN). Mortality high (medical comorbidities).
- **Rapid Rev:** Extracapsular = good union; DHS for stable, IM nail for unstable.
- **SBA:** Treatment of choice for stable intertrochanteric #: **Dynamic Hip Screw (DHS)**.
- **MCQ:** Intertrochanteric # has: **good blood supply → unites well**.
- **Explanation:** Extracapsular vessels intact.
- **Trend:** Very high; fixation choice.
- **Clinical:** Elderly, osteoporosis.
- **Examiner Tip:** Unlike neck #, AVN is NOT a worry here.
- **Ref:** Campbell.

## 48. Femoral Shaft Fracture ⭐⭐⭐⭐⭐
- **Notes:** Winquist classification (comminution). Rx: closed intramedullary nailing (antegrade). Child: elastic stable IM nail (ESIN). Risk: haemorrhage (up to 1.5 L), fat embolism.
- **Rapid Rev:** IM nail = standard. Paediatric = ESIN/TEN.
- **SBA:** Definitive fixation of adult femoral shaft #: **intramedullary nailing**.
- **MCQ:** Winquist classification grades: **comminution of femoral shaft #**.
- **Explanation:** Nail = load-sharing, early mobilisation.
- **Trend:** Very high; fixation.
- **Clinical:** RTA, pathology #.
- **Examiner Tip:** Femoral # = major haemorrhage source.
- **Ref:** Rockwood.

## 49. Supracondylar Humerus Fracture ⭐⭐⭐⭐⭐
- **Notes:** Children (fall on outstretched hand). Gartland I (non-displaced), II (angulated, intact posterior cortex), III (fully displaced). Complications: anterior interosseous nerve (AIN, branch of median → cannot make "OK" sign), brachial artery injury, Volkmann ischaemia.
- **Rapid Rev:** Gartland III = displaced. AIN = "OK" sign lost.
- **SBA:** Nerve most often injured in supracondylar #: **anterior interosseous (median branch)**.
- **MCQ:** Volkmann ischaemic contracture follows: **untreated elevated compartment pressure (supracondylar #)**.
- **Explanation:** Swelling/cast compresses forearm compartments.
- **Trend:** Very high; nerve/artery.
- **Clinical:** 5–7 yr child.
- **Examiner Tip:** AIN = cannot flex IP thumb (no OK sign); not radial.
- **Ref:** Apley.

## 50. Colles' Fracture ⭐⭐⭐⭐⭐
- **Notes:** Distal radius metaphyseal # with dorsal displacement/shortening → "dinner-fork" deformity. Elderly osteoporotic women. Rx: closed reduction + plaster (below-elbow). Complication: malunion (dinner-fork), median nerve, CRPS, EPL rupture.
- **Rapid Rev:** "Dinner fork" = Colles (dorsal). Smith = volar (reverse).
- **SBA:** Dinner-fork deformity is characteristic of: **Colles' fracture**.
- **MCQ:** Colles' # is a fracture of: **distal radius (within 2–3 cm of wrist)**.
- **Explanation:** Dorsal angulation of distal fragment.
- **Trend:** Very high; image-based.
- **Clinical:** FOOSH, osteoporosis.
- **Examiner Tip:** Smith = volar (not dinner-fork).
- **Ref:** Apley.

## 51. Scaphoid Fracture ⭐⭐⭐⭐⭐
- **Notes:** FOOSH; tenderness in anatomical snuffbox. Waist most common; proximal pole = AVN risk (retrograde blood from dorsal carpal branch). Rx: thumb spica cast; non-union → scaphoid non-union advanced collapse (SNAC).
- **Rapid Rev:** Snuffbox tenderness = scaphoid. Proximal pole = AVN.
- **SBA:** Scaphoid # with AVN risk involves: **proximal pole**.
- **MCQ:** Best initial investigation if X-ray normal but snuffbox tender: **scaphoid views / MRI / repeat X-ray at 10–14 d**.
- **Explanation:** Early X-ray may miss; MRI sensitive.
- **Trend:** Very high; AVN + snuffbox.
- **Clinical:** Young adult FOOSH.
- **Examiner Tip:** Proximal pole (not waist) = highest AVN.
- **Ref:** Apley.

## 52. Tibial Plateau Fracture ⭐⭐⭐⭐
- **Notes:** Schatzker I–VI (I lateral split, II depression, III posteromedial, IV medial/Tibial spine, V bicondylar, VI metaphyseal-diaphyseal dissociation). Association: ligament/meniscus injury, compartment syndrome. Rx: ORIF / external fixator.
- **Rapid Rev:** Schatzker = tibial plateau. VI = most severe.
- **SBA:** Schatzker classification is used for: **tibial plateau fractures**.
- **MCQ:** Tibial plateau # is commonly associated with: **meniscal/ligament injury & compartment syndrome**.
- **Explanation:** High-energy split/depression.
- **Trend:** High; classification.
- **Clinical:** Valgus load, elderly.
- **Examiner Tip:** Check knee ligaments in every plateau #.
- **Ref:** Schatzker; Rockwood.

## 53. Ankle Fracture ⭐⭐⭐⭐⭐
- **Notes:** Weber (A = below syndesmosis, B = at, C = above; C = worst, syndesmosis injured). Lauge-Hansen (supination-external rotation most common). Bimalleolar = medial+lat; trimalleolar + posterior. Rx: ORIF if displaced.
- **Rapid Rev:** Weber C = above syndesmosis = unstable.
- **SBA:** Most unstable ankle #: **Weber C (syndesmosis disrupted)**.
- **MCQ:** Lauge-Hansen most common pattern: **supination-external rotation**.
- **Explanation:** Higher Weber = more ligamentous injury.
- **Trend:** Very high; Weber classification.
- **Clinical:** Inversion/eversion injury.
- **Examiner Tip:** Weber B = at the syndesmosis (not below).
- **Ref:** Rockwood.

## 54. Calcaneal Fracture ⭐⭐⭐⭐
- **Notes:** Fall from height; intra-articular (75%). Böhler's angle (normal 20–40°) ↓ on lateral X-ray. Sanders CT classification. Complications: subtalar arthritis, compartment syndrome.
- **Rapid Rev:** Böhler's angle <20° = #. Fall from height.
- **SBA:** Reduced Böhler's angle suggests: **calcaneal fracture**.
- **MCQ:** Mechanism of calcaneal #: **axial loading (fall from height)**.
- **Explanation:** Talus drives into calcaneus.
- **Trend:** High; Böhler's angle numerical.
- **Clinical:** Jump/fall.
- **Examiner Tip:** Always check spine (lumbar) with calcaneal # (axial load).
- **Ref:** Rockwood.

## 55. Hip Dislocation ⭐⭐⭐⭐⭐
- **Notes:** Posterior 90% (dashboard, flexed knee) → short, adducted, internally rotated, flexed. Sciatic nerve (common peroneal) injured. Anterior → externally rotated, abducted. Reduce urgently (<6–12 h) to avoid AVN.
- **Rapid Rev:** Posterior = short + IR + adducted; sciatic nerve.
- **SBA:** Most common hip dislocation: **posterior (90%)**.
- **MCQ:** Nerve injured in posterior hip dislocation: **sciatic (common peroneal branch)**.
- **Explanation:** Femoral head exits posteriorly → stretches sciatic.
- **Trend:** Very high; position + nerve.
- **Clinical:** RTA.
- **Examiner Tip:** Posterior = internal rotation; anterior = external rotation.
- **Ref:** Apley.

## 56. Pelvic Fracture ⭐⭐⭐⭐
- **Notes:** Tile A (stable), B (partial stable, open-book/APC), C (unstable, vertical shear/LC). Major haemorrhage (retroperitoneal, venous). Pelvic binder; embolisation; APR if open.
- **Rapid Rev:** Tile C = unstable/vertical shear. Binder first.
- **SBA:** Unstable vertical-shear pelvic #: **Tile C**.
- **MCQ:** Initial stabilisation of unstable pelvic #: **pelvic binder / external fixator**.
- **Explanation:** Binder reduces volume, tamponades bleeding.
- **Trend:** High; Tile + haemorrhage.
- **Clinical:** High-energy RTA.
- **Examiner Tip:** Open-book (APC) = external rotation; bind immediately.
- **Ref:** Rockwood; ATLS.

## 57. Open Fracture ⭐⭐⭐⭐⭐
- **Notes:** Gustilo-Anderson I (<1 cm, clean), II (1–10 cm), IIIA (severe soft tissue but coverable), IIIB (needs flap), IIIC (arterial injury). Rx: urgent debridement <6–8 h, ABx (cefazolin ± aminoglycoside ± penicillin), tetanus, stabilise, soft-tissue coverage.
- **Rapid Rev:** Gustilo III = high energy. IIIC = vessel.
- **SBA:** Open # with arterial injury: **Gustilo IIIC**.
- **MCQ:** Antibiotics for open # should be given: **as early as possible (within 1 h), pre-debridement**.
- **Explanation:** Debridement + early ABx ↓ infection.
- **Trend:** Very high; Gustilo + management.
- **Clinical:** RTA, farming injuries.
- **Examiner Tip:** Debridement timing is the single biggest infection determinant.
- **Ref:** AO Principles; Gustilo.

## 58. Paediatric Fractures ⭐⭐⭐⭐⭐
- **Notes:** Greenstick (incomplete, bent), torus/buckle (impaction), plastic deformity. Salter-Harris (physeal): I transverse through physis, II (most common, metaphysis + physis), III (physis + epiphysis, intra-articular), IV (through all 3), V (crush physis). Complications: growth arrest (III/IV/V).
- **Rapid Rev:** SALTR mnemonic: I Straight, II Above, III Lower (epi), IV Through, V cRush.
- **SBA:** Most common Salter-Harris #: **Type II**.
- **MCQ:** Type V Salter-Harris is: **compression/crush injury of physis (growth arrest)**.
- **Explanation:** Physeal plate damage → limb length discrepancy.
- **Trend:** Very high; Salter-Harris.
- **Clinical:** Child fractures.
- **Examiner Tip:** Type II = "Above" metaphysis; most common.
- **Ref:** Apley.

## 59. Fat Embolism ⭐⭐⭐⭐⭐
- **Notes:** After long-bone # (femur/tibia) / pelvic. Triad: respiratory distress, petechial rash (conjunctiva/upper body), CNS confusion. Supportive; prophylaxis = early fixation.
- **Rapid Rev:** Petechiae + dyspnoea + long-bone # = fat embolism.

## 95. Giant-Cell Tumour ⭐⭐⭐⭐⭐
- **Notes:** Epiphysis (around knee — distal femur/proximal tibia), 20–40 yr. Soap-bubble / expansile lytic; Campanacci grading. "Osteoclastoma." Rx: curettage + cement/graft; denosumab; malignant transformation rare.
- **Rapid Rev:** Epiphysis + soap-bubble = GCT.
- **SBA:** Soap-bubble appearance = **giant-cell tumour**.
- **MCQ:** Giant-cell tumour typically occurs in: **epiphysis (around knee)**.
- **Explanation:** Locally aggressive, rarely malignant.
- **Trend:** Very high; location + sign.
- **Clinical:** Young adult knee.
- **Examiner Tip:** GCT = EPIPHYSIS (not metaphysis like osteosarcoma).
- **Ref:** Robbins.

## 96. Soft-Tissue Sarcoma ⭐⭐⭐⭐
- **Notes:** Deep, >5 cm, painful, fixed; staging size/depth/grade + metastasis (lung). Rx: incisional biopsy then wide (compartment) excision ± radiotherapy; limb-salvage.
- **Rapid Rev:** "Deep + >5 cm" → sarcoma workup.
- **SBA:** Management principle for suspected soft-tissue sarcoma: **planned incisional biopsy then wide excision**.
- **MCQ:** Most common site of metastasis: **lung**.
- **Explanation:** Bad biopsy worsens outcome.
- **Trend:** High; biopsy principle.
- **Clinical:** Extremity mass.
- **Examiner Tip:** Plan biopsy with oncologic surgeon.
- **Ref:** Schwartz; Campbell.

## 97. Polytrauma (Ortho) ⭐⭐⭐⭐⭐
- **Notes:** Multiple injuries; ATLS; damage-control ortho (external fixator temporising for femur/pelvis); prioritise life > limb; early total care vs damage control.
- **Rapid Rev:** Life before limb. Temporary fixator then definitive.
- **SBA:** In polytrauma with femur #, initial stabilisation: **external fixator (damage control)**.
- **MCQ:** Damage-control ortho aims to: **temporise fixation to allow resuscitation**.
- **Explanation:** Avoids prolonged anaesthesia in unstable patient.
- **Trend:** High; trauma.
- **Clinical:** RTA.
- **Examiner Tip:** Convert to IM nail once stable.
- **Ref:** ATLS; Rockwood.

## 98. Osteoporosis ⭐⭐⭐⭐⭐
- **Notes:** Low bone mass; DEXA T-score ≤−2.5. Post-menopausal (type I) & senile (type II). Rx: bisphosphonate, Ca²⁺/vit D, fall prevention. Atypical femur # (bisphosphonate). Vertebral/wrist/hip #.
- **Rapid Rev:** T-score ≤−2.5 = osteoporosis. T −1 to −2.5 = osteopenia.
- **SBA:** Diagnosis of osteoporosis: **DEXA T-score ≤ −2.5**.
- **MCQ:** Bisphosphonates are first-line for: **osteoporosis**.
- **Explanation:** ↓ resorption → ↑ density.
- **Trend:** Very high; DEXA.
- **Clinical:** Elderly women.
- **Examiner Tip:** Osteopenia = T −1 to −2.5 (not osteoporosis).
- **Ref:** Apley.

## 99. Imaging in Ortho ⭐⭐⭐⭐⭐
- **Notes:** X-ray: 2 views (AP/lat) always; stress/oblique as needed. CT: complex #, pelvis, spine. MRI: soft tissue, AVN, disc, tumour, infection. Bone scan: metastases, stress #, occult. USG: DDH <6 mo, soft tissue, effusion.
- **Rapid Rev:** X-ray 1st; MRI soft tissue/AVN; bone scan metastases.
- **SBA:** Investigation of choice for AVN: **MRI**.
- **MCQ:** DDH <6 months: **ultrasound**.
- **Explanation:** Modality matched to tissue.
- **Trend:** Very high; "investigation of choice" stems.
- **Clinical:** All ortho.
- **Examiner Tip:** Bone scan sensitive but not specific.
- **Ref:** Apley.

## 100. Principles of Fracture Fixation ⭐⭐⭐⭐⭐
- **Notes:** AO/ASIF principles: anatomical reduction, stable fixation, preservation of blood supply (biological), early motion. Absolute stability (compression plate) vs relative stability (IM nail/ex-fix). ORIF vs MIPO/BO (biological osteosynthesis). Tension band (patella, olecranon).
- **Rapid Rev:** AO = reduce, fix, preserve biology, move early.
- **SBA:** AO principle emphasising biology: **preserve blood supply (minimally invasive / biological fixation)**.
- **MCQ:** Tension-band principle used for: **patella & olecranon fractures**.
- **Explanation:** Converts tension → compression at fracture.
- **Trend:** Very high; principles.
- **Clinical:** Every #.
- **Examiner Tip:** Absolute stability = compression; relative = IM nail.
- **Ref:** AO Principles.

## 5A. RAPID REVISION (one-liners)
**Nerves:** Erb C5–C6 (waiter's tip) · Klumpke C8–T1 (claw+Horner) · Axillary = surgical neck → deltoid · Radial = spiral → wrist drop · Median (AIN) = supracondylar → no OK sign · Common peroneal = fibular neck → foot drop · Sciatic = post hip dislocation.
**Hip blood:** MCFA retinacular = head supply; intracapsular # → AVN.
**Calcium:** PTH↑Ca, calcitonin↓Ca, vit D = gut absorption; active = 1,25-OH (kidney).
**Bone tumours:** Osteo=metaphysis/sunburst/Codman · Ewing=diaphysis/onion/t(11;22) · GCT=epiphysis/soap-bubble · Metastasis=most common (prostate blastic, breast/lung lytic).
**Classifications:** Garden (NOF) · Gustilo (open) · Salter-Harris (physeal) · Weber (ankle) · Gartland (supracondylar) · Schatzker (plateau) · Evans (intertroch) · Cobb (scoliosis) · Meyerding (spondylolisthesis) · Tile (pelvis) · Herring (Perthes) · Campanacci (GCT) · Klein (SCFE) · Böhler (calcaneus).
**"Most common":** organism = S. aureus · child bone tumour = osteosarcoma · adult bone tumour = metastasis · osteo site kids = metaphysis · AVN = NOF/trauma/steroids · congenital = CTEV · limp child = transient synovitis · joint replaced = knee>hip.
**Red flags:** Cauda equina (saddle + retention) · compartment (pain+passive stretch; pulseless=LATE) · gas gangrene (crepitus) · Pott's (cold abscess+angular kyphosis) · septic arthritis (hot joint → aspirate first).

## 5B. FLOWCHARTS (ASCII)
**Acute swollen joint:**
```
Swollen joint ─ Hot/red/fever? ─ YES → Septic arthritis → ASPIRATE before ABx → drain+ABx
                │ NO
                └─ Monoarticular? ─ Gout (neg needle, 1st MTP) / Pseudogout (pos, knee)
                   Polyarticular? ─ RA (MCP/PIP, swan-neck) / AS (bamboo, HLA-B27)
```
**Child with limp:**
```
Limp ─ <3 mo: Barlow/Ortolani? ─ YES → DDH
       │ NO
       ├─ Fever+localised thigh pain → Osteomyelitis / Septic arthritis (aspirate)
       ├─ 4–8 yr, painless limp → Perthes (AVN)
       ├─ Obese adolescent, knee→hip → SCFE (Klein)
       ├─ No fever, self-limited → Transient synovitis (most common)
       └─ Foot deformity → CTEV
```
**Suspected compartment syndrome:**
```
Pain + tense swelling + pain on PASSIVE STRETCH → measure pressure (>30 mmHg) → URGENT FASCIOTOMY
   (Do NOT wait for pulselessness/paralysis — those are LATE)
```
**Open fracture:**
```
Open # ─ Tetanus status ─ ABx (cefazolin±amino/pen) within 1 h ─ Debridement <6–8 h
        ─ Stabilise (fixator/ORIF) ─ Soft-tissue cover
```
**Hip pain in elderly after fall:**
```
X-ray ─ NOF (intracapsular) displaced → AVN risk → arthroplasty
        ─ Intertrochanteric → DHS/IM nail (good union)
        ─ Posterior dislocation → reduce <6–12 h (sciatic nerve)
```
